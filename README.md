## 一、这是什么

<sup>一个给孩子做**英语每日刷题**的网页小工具。</sup>

<sup>孩子打开网页 → 点一下「每日 10 题」→ 做完点「提交答案」→ 系统立刻判分、标出错题、给出中文解析 → 错题自动进入「错题本」，第二天再练时**优先出现还没掌握的错题**。</sup>

<sup>题目不是凭空编的，而是**从这几份真实材料里逐题抠出来的**：</sup>

- <sup>**沪教牛津版 6AU1《School life》单元知识单**（P14–17，1–32 条）——当前正在学的课文词汇；</sup>
- <sup>**6A 全册教材词汇与考纲**——打底的语法点；</sup>
- <sup>**词型结构速记手册**（11 组 276 条固定搭配）——`want to do` / `stop doing` / `give up` 这类最容易混的结构。</sup>

<sup>每道题都能点开看到**中文解析**：不但说"为什么选它"，还会逐个点破干扰项错在哪。每道题都标了**难度**和**出处**，家长一眼就知道这是学校卷原题、还是练习册错题。</sup>

## 二、快速开始

1. <sup>**下载本仓库**，找到文件 `六年级英语每日刷题_v2.html`；</sup>
2. <sup>**双击它**，用浏览器打开（推荐 Chrome / Edge）；</sup>
3. <sup>点首页的 **🎯 每日 10 题**，直接开练。</sup>

> <sup>如果你是通过 GitHub 网页浏览的：点右上角 `Code` → `Download ZIP` 下载后本地打开；或者直接访问已开启的 GitHub Pages 网址（`https://<你的用户名>.github.io/<仓库名>/`），效果完全一样。</sup>

<sup>**手机 / 平板**：浏览器直接打开同一个 `六年级英语每日刷题_v2.html` 即可，页面带 viewport 声明并使用自适应网格，题目和选项会自动换行；不过按钮偏小，孩子独立操作建议以平板或电脑为主。</sup>

<sup>**不需要注册、不需要联网、不上传任何数据**——所有答题记录只存在你自己这台电脑的浏览器里。</sup>

## 四、每天怎么用（建议节奏）

<sup>**每天 10 分钟，固定顺序：**</sup>

1. <sup>**首页 → 🎯 每日 10 题**（约 5 分钟）</sup>

   <sup>"智能推荐"会优先挑**还没掌握的错题**，其次是没做过的新题，最后才是复习题 —— 所以不用自己挑题，它自动帮你查漏补缺。</sup>

2. <sup>**提交后看解析**（约 3 分钟）</sup>

   <sup>答错的题会标红、正确答案标绿，并展开中文解析。**别只看对错，要看解析里点破的那个坑。**</sup>

3. <sup>**📚 知识点 查一下刚才错的考点**（约 2 分钟）</sup>

   <sup>对应分类里有规则 + 例句 + 易错提示，背下那句口诀。</sup>

4. <sup>**周末加练 → ⚡ 每日 20 题**，或用「每日刷题」页按**考点**专项突破某个薄弱模块。</sup>

> <sup>🖨 **想要纸质练习卷**：刷题页点「🖨 打印本轮」，会输出一份**不带答案**的 A4 练习卷（带姓名/班级/日期栏），打印出来给孩子做，很适合周末。</sup>
